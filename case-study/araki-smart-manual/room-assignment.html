チェックイン前の重要作業

部屋の割り当て（アサイン）

予約した部屋タイプに対して、実際に使用する部屋番号を決めます。手動・自動の違いと、割り当て後の確認方法をまとめます。

1. アサインとは

予約時点では「ツインを1室」のように部屋タイプだけが決まり、具体的な部屋番号が未定の場合があります。アサインは、その予約に「203号室」のような実際の部屋を割り当てる操作です。

方法使用する場面担当
手動割当特定の部屋を指定したい、当日の未割当を処理したいフロント／責任者
自動部屋割り設定した時期に、部屋タイプと優先ルールから自動で決める設定変更は管理者
フロア一括割当修学旅行など、団体でフロア全体を事前確保する責任者のみ

2. 割り当てる前の確認

  • 施設名と表示日が正しい
  • 予約の宿泊日・泊数・人数が正しい
  • 予約の部屋タイプと、割り当てる部屋のタイプが一致する
  • 部屋の定員を超えていない
  • 同じ期間に別予約や客室ブロックがない
  • 到着時刻までに清掃完了できる
  • 連泊途中で意図しない部屋移動が発生しない
  • 禁煙・階数・近接部屋などの希望と共有事項を確認した
空いて見えても即決しない清掃中、修理予定、前後予約の時刻重複、連泊の途中など、一覧だけでは判断できない場合があります。

3. 予約詳細から手動で割り当てる

公式フロント運用PDFで確認できた手順です。団体予約や複数部屋予約でも使用します。

予約管理 → 予約情報 → 対象予約の詳細 → 宿泊変更 → 部屋変更
  1. 対象予約を開き、氏名・宿泊日・人数を照合します。
  2. 「宿泊変更」の「部屋変更」を開きます。
  3. 割り当てる日付の「未割当」セルをクリックします。
  4. プルダウンから、予約した部屋タイプに合う部屋番号を選びます。
  5. 連泊の場合は、すべての日付が同じ部屋になっているか確認します。
  6. 宿泊者台帳で、宿泊者と部屋の対応も確認します。
  7. 予約を保存し、もう一度予約詳細を開いて部屋番号を確認します。
団体予約代表者だけでなく、各部屋の人数と宿泊者の割り当ても確認します。特定の部屋だけ日程が異なる場合は「日程削除」を使うケースがありますが、通常の部屋割りでは使用しません。
完了の目安予約詳細の全宿泊日に正しい部屋番号が表示され、未割当が残っていません。

4. 「部屋割り表」で未割当を確認する

予約管理 → 部屋割り表

実画面では、次の項目を確認できました。

  • 施設の選択
  • 2週間表示／基準日表示、基準日の変更
  • 「未部屋割り一覧」と未割当数
  • スケジュールバー、部屋タイプ、代表者／人数、部屋数、予約経路、利用期間
  • グループ・子どもあり表示、絞り込みモード
  • 部屋割り状況表、複数予約あり、ブロック中、フロア絞り込み
  • 「自動割当」ボタン
手動操作は確認待ち未部屋割り一覧にはドラッグ用と思われる「スケジュールバー」がありますが、確認環境は未割当0件でした。ドラッグ先、保存のタイミング、警告表示を実操作できていないため、現時点では正式手順にしていません。通常スタッフは、上の「予約詳細から手動で割り当てる」を使用してください。

5. 自動部屋割りの仕組み

物件管理 → 物件情報 → 詳細を見る → 自動部屋割り設定
管理者のみ設定変更
  1. 自動部屋割りの時期を、チェックイン当日から90日前の範囲で選びます。
  2. 必要に応じてローテーション部屋割りと、部屋ごとの優先順位を設定します。
  3. 設定された時期になると、午前1時頃から日次バッチで割り当てられます。
  4. 割当時期を過ぎてから入った予約は、即時に割り当てられます。
  5. 割当後は「部屋割り表」または予約詳細で結果を確認します。
複数部屋がある施設の公式推奨「当日チェックインの予約のみ実行」が推奨されています。早く割り当てすぎると、連泊予約に部屋移動が発生したり、OTAからの部屋タイプ変更が反映されなくなったりするためです。

割り当て順

設定割り当て方
ローテーション部屋割り：行う空室期間が長い部屋を優先。部屋割り優先順位より先に適用されます。
空室期間が同じ設定した部屋割り優先順位を適用します。
同じ優先順位定員数が小さい部屋を優先します。
優先順位が未設定設定済みの部屋より後になります。
一度割り当てると外部変更が反映されない場合があります公式記事では、割当後にOTA・サイトコントローラーから部屋タイプ変更通知が来ても反映されないと説明されています。外部予約の部屋を手動変更する前に責任者へ確認します。

6. 自動部屋割りが行われない／失敗した

確認すること内容
部屋タイプ予約と各部屋に部屋タイプが設定されているか
実行時期設定した「チェックイン何日前」の時期に達しているか
空室対象部屋タイプに空きがあるか。前後予約の入退室時刻も確認
定員予約人数が部屋詳細の定員を超えていないか
ブロック故障・修理などのブロック期間と重なっていないか
エラーを消すために別タイプへ入れない予約の部屋タイプ、料金、在庫が食い違う可能性があります。失敗通知と対象予約を記録し、責任者へ連絡します。

未割当予約の探し方

方法1：予約管理 → 予約情報 → 条件を選択して絞り込み → 部屋割当状況「未部屋割り」

方法2：予約管理 → 部屋割り表 → 基準日を指定 → 未部屋割り一覧

7. フロア一括割当

責任者のみ

修学旅行などで、指定したフロアの全客室を新規予約時に確保する機能です。通常予約には使用しません。

  • フロアと各部屋の階数設定が必要
  • 予約詳細表示設定で「フロア一括割当」を有効にする必要がある
  • 新規予約の作成時だけ使用できる
  • 既存予約の変更には「宿泊変更」を使用する
オーバーブッキングでも保存できる仕様です公式記事では警告後にOKを押すと保存できるとされています。あらきホテルでは運用ルールが確定するまで、警告を進めず責任者へ連絡してください。

8. 割り当てを変更・解除する

予約詳細 → 宿泊変更 → 部屋変更
  1. 変更理由と対象日を確認します。
  2. 移動先の空室・清掃・ブロック・定員を確認します。
  3. 対象日のセルから新しい部屋を選択します。
  4. 連泊の途中変更なら、移動日以前と以後の部屋番号を確認します。
  5. 保存後、鍵・清掃・次シフトへ旧部屋と新部屋を共有します。
「割当解除」「日程削除」は別の操作です割当解除は部屋番号を外す操作、日程削除はその部屋の利用日程を予約から外す操作です。目的が分からない場合は押しません。

9. HOTEL SMART・現場への確認待ち

下記が確定するまで、「部屋割り表」でのドラッグ操作と設定変更は責任者対応とします。

  • 部屋割り表での正式なドラッグ＆ドロップ手順と、保存されるタイミング
  • 部屋割り表の「自動割当」ボタンが、定期バッチとどう違うか
  • 手動で割当解除した予約が、次の自動処理で再割当されるか
  • 清掃状態は割当候補の判定に使われるか
  • 割当後にOTAの部屋タイプ変更を反映する正式な手順
  • 誤割当の操作履歴・変更者を確認できるか
  • あらきホテルで現在設定されている実行時期・ローテーション・優先順位
  • フロア一括割当を無効化または権限制限できるか
