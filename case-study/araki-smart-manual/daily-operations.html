1. 出勤したら最初にすること

開く画面：ダッシュボード
  • 自分のアカウントでログインした
  • 前のシフトからの引継ぎを読んだ
  • 本日の到着・出発・連泊の件数を確認した
  • 未割当の予約、未精算、注意が必要なお客様を確認した
  • 清掃担当へ伝える部屋変更・到着時刻変更がないか確認した
完了の目安「今日、誰が来て、誰が帰り、何に注意するか」を口頭で説明できれば完了です。

ログイン後の最初の画面です。予約の詳細を編集する前に、今日の全体像を確認します。

3. 客室状況を確認する

左メニュー → 客室の状況表
表示意味フロントの対応
空室／利用可能予約・滞在・ブロックがない部屋清掃状態も確認してから割り当てる
到着予定本日チェックイン予定氏名・人数・支払い・連絡事項を確認
滞在中チェックイン済み部屋移動や延泊は予約詳細から処理
出発予定本日チェックアウト予定未精算と追加利用を確認
ブロック故障・工事などで販売停止中理由と期間を確認し、勝手に解除しない
色だけで判断しない色の設定は施設や画面更新で変わることがあります。必ず表示名と予約詳細を確認してください。

4. チェックインする

客室の状況表 → スマート予約検索 → 対象の部屋を開く
  1. お客様の氏名を伺い、画面上部の「スマート予約検索」で対象の予約を特定します。複数条件はスペースで区切って入力でき、必要に応じて「過去分も表示」「本日チェックアウト」も使います。
  2. 宿泊日、人数、部屋タイプ、連絡事項を読み合わせます。
  3. 宿泊者情報と本人確認書類など、施設で必要な項目を確認します。
  4. 部屋番号と清掃完了を確認します。未割当なら責任者ルールに沿って割り当てます。
  5. 未収金が赤字で表示されていないか確認し、必要な精算を行います。
  6. 「チェックイン」を実行し、画面が滞在中になったことを確認します。
  7. 鍵と館内案内をお渡しします。
いったん止める場合予約が見つからない、宿泊日や人数が違う、部屋が未清掃、支払額が予約確認書と違う場合は、推測で変更せず「困ったとき」を確認して責任者へ連絡します。
完了の目安予約状態が「滞在中」になり、部屋番号・支払い・鍵の受け渡しが一致しています。

5. チェックアウトする

左メニュー → 予約管理 → 対象予約を開く
  1. 氏名または部屋番号で予約を開きます。
  2. 宿泊代、追加料金、入金済み金額を確認します。
  3. 未精算があれば支払方法を確認して精算します。
  4. 領収書が必要か、宛名・但し書きを確認します。
  5. 鍵の返却を確認し、予約詳細の右上のステータスから「チェックアウト済みにする」を選び、チェックアウトする部屋を選んで実行します。
  6. ステータスが「チェックアウト済み」になったことを確認し、清掃担当へ共有します。
追加利用を先に確認飲食・売店・延長などがある場合は、チェックアウトを押す前に明細へ反映します。

6. 次のシフトへ引き継ぐ

「見れば分かる」ではなく、次の人が迷わず行動できる形で残します。

  • 未到着・遅着のお客様と連絡状況
  • 未精算、金額差異、返金待ち
  • 部屋移動、故障、ブロック、清掃待ち
  • 貸出品・手配品・特別対応
  • お客様からの依頼と、次に誰が何をするか
書き方の例「305号室 田中様／延長コード貸出中／返却はチェックアウト時／次の担当者が返却確認」のように、対象・内容・済んだこと・残ることを書きます。

7. 日次締め（責任者）

管理者・責任者のみ

営業日の売上や入金を確定する処理です。施設で機能を有効化している場合、設定した締め時刻を過ぎると日次締め画面に「日次の締めを行う」ボタンが表示され、責任者が確認してから押して締めます。

初回の有効化は管理者だけあらきホテルで使用する方針、担当者、締め時刻、照合方法を決めた後、【売上管理】→【日次締め機能】で対象物件と締め時刻を確認し、「日次締め機能を有効化する」を実行します。通常のフロントスタッフは設定しません。日次締め機能は、一度有効化すると管理画面から無効化できません。また、有効化した時点ですでにその日の締め時刻を過ぎていると、前日以前の分がその場で締め済みになりました（2026/10/06確認）。締め済みの日の予約・料金・精算は変更できなくなるため、有効化する前に、直しておくべき予約や精算が残っていないか確認してください。

種子島あらき別館では、締め時刻（毎日04:00）を過ぎると、日次締め画面の一番下に「日次の締めを行う」ボタンが表示されます。締め時刻を過ぎても自動では締められません（2026/10/07確認）。締め時刻を過ぎたら、責任者が次の手順で締めます。

  1. 【売上管理】→【日次締め機能】を開き、「再取得」で最新の状態にして、対象日（まだ締めていない日付）と、注意点のある予約・精算情報・前受金情報を確認します。
  2. 対象日（締める日）のチェックイン・チェックアウト漏れがないか確認します。
  3. 未精算、現金・カードなど支払別の差異を確認します。
  4. 未対応の予約や明細がないか確認します。
  5. 差異や未処理があれば、締める前に対応します。
  6. 問題がなければ「日次の締めを行う」を押し、「（物件名）の（日付）分の売上・売掛金を締めますか？」の確認で物件名と日付を確かめてからOKを押します（2026/10/07確認）。
締めた後のデータは編集できません公式フロント運用マニュアルでは、日次締め済みデータは編集不可とされています。締めた後は変更できないため、差異や未処理は「日次の締めを行う」を押す前に対応してください。
現在の実画面種子島あらき別館：日次締め機能を有効化済み（締め時刻は毎日04:00）。締め時刻を過ぎると「日次の締めを行う」ボタンが表示され、押して締めます（2026/10/07確認）。種子島あらきホテル：未有効化（2026/10/06確認）。
