1. 客室状況を確認する

左メニュー → 客室の状況表
  1. 画面の日付が今日になっていることを確認します。公式マニュアルでは、日次締めを使っている物件の状況表は「締めが終わった日の次の日」の日付で開くとされています。締めがまだの朝は前日の日付で開くので、日付を今日に切り替えます（前日より前の日付は見られません）。
  2. チェックイン予定、宿泊中、チェックアウト待ち、清掃待ち・清掃中、空室、ブロック中の部屋を確認します（画面のステータス名です。意味とアイコンは1日の業務の「客室状況を確認する」の表を見ます）。
  3. 左のステータス一覧の「未部屋割りの予約」の件数を見ます。部屋が決まっていない予約は、状況表の部屋の一覧には出ません。1件以上あれば、部屋割り表の「未部屋割り一覧」で割り当てます（公式マニュアルより。割当先の候補になる部屋には吹き出しのアイコンが付きます）。
  4. 未清掃のまま到着時刻が近い部屋を清掃担当へ伝えます。
色だけで判断しない必ず部屋番号、宿泊者名、宿泊日、画面に表示された状態名を読みます。
同じ日に出発と到着がある部屋（公式マニュアルより）清掃予定がある部屋は、清掃を完了にするまで、次に到着するお客様の予約が状況表に出ません。あらきホテルは清掃予定を自動で作る設定なので、清掃予定表で「清掃済」にするまで、その部屋は「清掃待ち」のまま残ります。到着のお客様が状況表で見つからないときは、まず清掃予定表を確認します（あらきホテルでは未確認）。また、ノーショウの部屋も清掃日には「清掃待ち」になります。
状況表で予約が見つからないとき部屋が決まっていない予約かもしれません。予約管理 → 予約情報で探します（予約が見つからない）。

2. 清掃状況を確認・更新する

左メニュー → 清掃管理 → 清掃予定表
  1. 対象日が今日になっているか確認します。
  2. 対象の部屋番号と清掃予定を確認します。
  3. 清掃担当者から完了報告を受けます。
  4. 部屋番号をもう一度読み合わせてから、清掃完了を登録します。右上の「一括操作」を押すと、画面下に操作バー（未手配を全選択／手配する／完了する／確認する）が出ます。清掃が終わった部屋の行にチェックを入れて「完了する」を押すと、確認画面なしで清掃状況が「清掃済」になり、「清掃員から」欄に「［ホストにより完了］」と記録されます（2026/10/09確認）。一括操作は清掃予定表の「日」「週」表示で使えます（月表示では使えません。公式マニュアルより）。1部屋だけなら、清掃予定表でその部屋の清掃予定を押し、〖データ操作〗の「清掃済みに変更する」でも完了にできます（公式マニュアルより。あらきホテルでは未確認）。
  5. 客室の状況表へ戻り、到着予定の部屋が案内可能か確認します。同じ日に出発と到着がある部屋は、清掃完了にした後で、到着の予約が状況表に出ているか確かめます（客室状況を確認するの注意）。

左メニュー［清掃管理］の下は「清掃予定表／組織設定／手配設定／費用単価設定／請求書発行」です。清掃予定表は、物件を選ぶまで「物件を選択してください」と表示されます。日／週／月の切り替えと、「新規作成」「一括操作」「印刷」ボタンがあります（2026/10/09確認）。

上部に、客室状況（空室／連泊／CO予定／CO済）、清掃状況（清掃待ち／清掃中／確認待ち／清掃済）、手配状況（未手配／手配済）の件数が出ます。表の列は、部屋番号/タイプ、客室状況、清掃状況、宿泊/人数、CO/CI予定、清掃業者/担当者、清掃時備考、清掃員へ/清掃員からです（2026/10/09確認）。

清掃予定は、予約を作ったときに自動で作られます。［清掃管理］→［手配設定］→ 物件の「詳細を見る」の「清掃予定自動作成」が「チェックアウト時のみ」になっています（選択肢はほかに「作成しない」「宿泊中は毎日」）。清掃日は予約のチェックアウト予定日です。10/9 の表が「清掃予定がありません」だったのは、10/9 にチェックアウト予定の部屋が無かったためです（2026/10/09確認）。

連泊中の清掃は表に出ません公式マニュアルでは、「宿泊中は毎日」を選ぶと1泊ごとに清掃予定が作られるとされています。あらきホテルの「チェックアウト時のみ」では、連泊中の部屋の清掃（ステイ清掃）は清掃予定表に出ません。必要なときは、清掃予定表の「新規作成」で手で作るか、清掃担当と紙などで共有します（どちらにするかは責任者が決めます。設定の変更は管理者の判断です）。

清掃予定表は日／週／月で切り替えられ、月表示では日ごとの件数（未手配・清掃待ちなど）が見られます。開いた直後は「清掃予定がありません」と出て、少し待つと一覧が出ることがありました。部屋が未割り当ての予約は、部屋番号の代わりに部屋タイプ（例：キャビン）が表示されます（2026/10/09確認）。

早めのチェックアウトは翌日の表も確認予定より早くチェックアウトしても、清掃予定は元のチェックアウト予定日のままです。例：10/10 チェックアウト予定の予約を 10/9 にチェックアウトすると、清掃予定は 10/10 の表に「CO済・清掃待ち」で出て、10/9 の表には出ません。早出の部屋の清掃を見落とさないよう、翌日の表も確認してください（2026/10/09確認）。
日程を変えたときの清掃予定（公式マニュアルより）予約のチェックアウト日を変える（延泊・減泊）と、自動で作られた清掃予定も新しい日程に合わせて作り直されます。上の例のようにチェックアウト処理だけをした場合は、元の予定日のままです。「新規作成」や「別日にコピーする」で手で作った・動かした清掃予定は、日程を変えても自動では動きません。予約をキャンセル・削除すると、その予約の清掃予定はすべて「キャンセル」になります（あらきホテルでは未確認）。
手配・清掃員からの報告は確認待ち清掃組織・清掃員は登録されていません（［組織設定］が空、手配設定の「対応組織」も空）。そのため「手配する」「確認する」と、清掃員アプリからの報告は未確認です。
報告前に「清掃完了」にしない画面上だけ完了にすると、未清掃の客室へお客様を案内する事故につながります。
完了の目安「実際の部屋」「清掃担当の認識」「PMSの表示」の3つが一致しています。

清掃予定表は印刷してメーキングリストとして使えます（公式マニュアルより。あらきホテルでは未確認）。

予約の「清掃時備考」は印刷に出ません公式マニュアルでは、予約詳細の共有事項にある「清掃時備考」は清掃業者・清掃員のアカウントを通じて伝わるもので、メーキングリストには表示されないとされています。あらきホテルは清掃員が登録されていないので、アメニティ追加などの指示は、口頭やメモで清掃担当へ直接伝えます。また、メーキングリストで部屋番号の無い行は、部屋が決まっていない予約の清掃予定です（公式マニュアルより）。

3. 滞在中のお客様が部屋を移る

  1. お客様の予約詳細を開き、移動する日付を確認します。
  2. 移動先の部屋が空室・清掃済みで、ブロックされていないことを確認します。
  3. 移動日以降の部屋割りを変更します。
  4. 宿泊日、旧部屋、新部屋、料金が意図どおりか確認して保存します。
  5. 鍵を交換し、旧部屋の鍵を回収します。
  6. 清掃担当と次のシフトへ、旧部屋・新部屋・移動日を共有します。
2つの方法を使い分ける宿泊期間全体の部屋を入れ替える（到着時に清掃が終わっていない、設備が故障した など）ときは「ルームチェンジ」を使います（ルームチェンジ）。連泊の途中から別の部屋へ移るときは、「宿泊変更」→「部屋変更」で移動日以降の部屋を変えます（部屋の途中変更）。
予約を作り直さない連泊途中の部屋移動は、公式マニュアル（PDF・オンライン版）では予約内の「宿泊変更」から行います。別予約を作ると料金・宿泊者・精算が分かれるため、自己判断で作り直しません。

4. 客室をブロックする

故障、修繕、館内利用などで販売・割当を止めるときに使います。

物件管理 → 部屋情報 → 対象の部屋の「詳細を見る」 → ブロック設定
  1. 対象の部屋番号、開始日時、終了日時を確認します。1泊分を止めるなら、翌日の0:00をまたぐ期間にします（例：当日15:00〜翌日11:00）。公式マニュアルでは、翌日の0時0分がブロック期間に入っていれば、その日はブロック扱いで在庫が減るとされています。
  2. 同じ期間に予約が入っていないか確認します。
  3. 部屋詳細の〖ブロック設定〗で「ブロック期間を追加する」を押し、期間を選んで「OK」を押します。メモ欄に故障などの理由と解除予定を書きます（メモは客室の状況表・部屋割り表に、予約者名の代わりに表示されます）。
  4. 「変更を保存する」を押して登録します。
  5. 客室の状況表で、対象期間が紫色の「ブロック中」になったことを確認します。
  6. 引継ぎへ「部屋・理由・期間・解除判断者」を残します。

解除するときは、同じ〖ブロック設定〗で行の「×」を押してから「変更を保存する」を押します。画面つきの詳しい手順は、部屋のブロックとブロックを解除するを見ます（2026/10/07確認）。

締め済みの日付は変更・削除できません公式マニュアルでは、日次締めを終えた日付のブロックは変更も削除もできないとされています。「予約が入っている期間には設定できない」は公式PDFの記載で、オンライン版には書かれておらず、あらきホテルの実画面でも未確認です。どちらの場合も、予約を勝手に移動したり、期間を変えて無理に登録したりせず、責任者へ相談します。

5. 変更を共有する

変更伝える相手伝える内容
部屋変更清掃担当・次シフト旧部屋、新部屋、移動日、鍵回収
延泊・早出清掃担当・会計担当新しい出発日、清掃日（チェックアウト日を変えると清掃予定も自動で移る）、料金への影響
故障・ブロック責任者・清掃担当部屋、理由、期間、代替対応
貸出品次シフト品名、貸出先、返却予定
基本ルール画面を直しただけで終わらず、相手が情報を受け取ったことまで確認します。
