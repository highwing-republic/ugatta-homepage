部屋の割り当て（アサイン）

予約した部屋タイプに対して、実際に使用する部屋番号を決めます。手動・自動の違いと、割り当て後の確認方法をまとめます。

1. アサインとは

予約時点では「ツインを1室」のように部屋タイプだけが決まり、具体的な部屋番号が未定の場合があります。アサインは、その予約に「203号室」のような実際の部屋を割り当てる操作です。

方法使用する場面担当
手動割当特定の部屋を指定したい、当日の未割当を処理したいフロント／責任者
自動部屋割り設定した時期に、部屋タイプと優先ルールから自動で決める設定変更は管理者
フロア一括割当修学旅行など、団体でフロア全体を事前確保する責任者のみ

2. 割り当てる前の確認

  • 施設名と表示日が正しい
  • 予約の宿泊日・泊数・人数が正しい
  • 予約の部屋タイプと、割り当てる部屋のタイプが一致する
  • 部屋の定員を超えていない
  • 同じ期間に別予約や客室ブロックがない
  • 到着時刻までに清掃完了できる
  • 連泊途中で意図しない部屋移動が発生しない
  • 禁煙・階数・近接部屋などの希望と共有事項を確認した
空いて見えても即決しない清掃中、修理予定、前後予約の時刻重複、連泊の途中など、一覧だけでは判断できない場合があります。

3. 予約詳細から手動で割り当てる

方法A：予約詳細の「部屋割り当て」で選ぶ（宿泊期間全体を同じ部屋にする）

予約管理 → 予約情報 → 対象予約の詳細 → 部屋割り当て

公式マニュアル（オンライン版）では、宿泊期間全体の部屋は予約詳細の［部屋割り当て］で選び、日ごとに部屋を変えるときだけ「宿泊変更」の「部屋変更」を使う、と分けて説明されています。［部屋割り当て］では、部屋ごとに部屋番号を選ぶか、「おまかせ割り当て」を押します。「おまかせ割り当て」は、自動部屋割り設定（ローテーション・優先順位）に沿って部屋を入れます（公式の本文では「おまかせ選択」と書かれています）。あらきホテルの画面でも、部屋番号が未入力の部屋に「おまかせ割り当て」ボタンが出ることを確認しています（部屋の追加／削除、2026/10/05確認）。部屋番号を選んだ後の保存の仕方は、あらきホテルでは未確認です。連泊でも全日に同じ部屋が入るので、入れ漏れが起きにくい方法です。

方法B：「宿泊変更」→「部屋変更」で日ごとに選ぶ（日ごとに部屋を変える／一部の日だけ割り当てる）

公式フロント運用PDFで確認できた手順です。団体予約や複数部屋予約でも使用します。

予約管理 → 予約情報 → 対象予約の詳細 → 宿泊変更 → 部屋変更
  1. 対象予約を開き、氏名・宿泊日・人数を照合します。
  2. 「宿泊変更」の「部屋変更」を開きます。
  3. 割り当てる日付の「未割当」セルをクリックします。
  4. プルダウンから、予約した部屋タイプに合う部屋番号を選びます。
  5. 連泊の場合は、すべての日付が同じ部屋になっているか確認します。
  6. 宿泊者台帳で、宿泊者と部屋の対応も確認します。
  7. 予約を保存し、もう一度予約詳細を開いて部屋番号を確認します。
団体予約代表者だけでなく、各部屋の人数と宿泊者の割り当ても確認します。特定の部屋だけ日程が異なる場合は「日程削除」を使うケースがありますが、通常の部屋割りでは使用しません。
完了の目安予約詳細の全宿泊日に正しい部屋番号が表示され、未割当が残っていません。

方法C：客室の状況表から割り当てる（その日に到着する予約）

公式マニュアルでは、客室の状況表から未部屋割りの予約を直接割り当てる方法が案内されています（あらきホテルでは未確認）。

  1. 客室の状況表で、吹き出しのアイコン（割り当て可能な予約あり）が付いた部屋を押します。
  2. 「未部屋割りの予約を割り当てる」を押し、割り当てる予約を選びます。
  3. 「割り当てる」を押します。

4. 「部屋割り表」で未割当を確認する

予約管理 → 部屋割り表

実画面では、次の項目を確認できました。

  • 施設の選択
  • 2週間表示／基準日表示、基準日の変更
  • 「未部屋割り一覧」と未割当数
  • スケジュールバー、部屋タイプ、代表者／人数、部屋数、予約経路、利用期間
  • グループ・子どもあり表示、絞り込みモード
  • 部屋割り状況表、複数予約あり、ブロック中、フロア絞り込み
  • 「自動割当」ボタン

未割り当ての予約があると「未部屋割り一覧」に1行ずつ並び、右上に「未割当数：14件」のように件数が出ます（2026/10/09確認）。列は、スケジュールバー／部屋タイプ／予約代表者／人数／部屋／全部屋数／予約経路／利用期間／自動割当（行ごとのボタン）です。

行ごとの「自動割当」：未部屋割り一覧の行の右にある「自動割当」を押すと、確認画面「自動割り当て」が開き、宿泊期間・予約代表者名・指定部屋タイプ・割当先部屋番号（例：417（ツイン））が表示されます。「割当をする」を押すとその場で割り当てられ、画面が読み込み直されます（別の保存は不要）（2026/10/09確認）。

右上の「自動割当」（全体）：押すと、表示中の基準日にかかっている未割り当ての予約がすべて一覧で表示され、割当先の部屋番号を確認できます。「割当をする」で全部まとめて割り当てます。割り当てられないものは「割り当てられる部屋がありません」と表示され、未割り当てのまま残ります。例：基準日 10/10 で実行すると、10/9〜10/10 の1泊の予約や、10/1〜11/1 の長期の予約も対象に入り、15件中13件に部屋が入りました（2026/10/09確認）。

その日にかかる長期の予約もまとめて割り当てます右上の「自動割当」は、表示中の日だけでなく、その日にかかる長期の予約もまとめて割り当てます。押す前に一覧の割当先を必ず確認してください。
ドラッグでの割り当ては確認待ちスケジュールバーをドラッグしても反応がなく、今回の確認では割り当てられませんでした（2026/10/09確認）。正しい操作方法は確認待ちのため、正式手順にしていません。通常スタッフは、上の「予約詳細から手動で割り当てる」を使用してください。公式マニュアル（手配品管理の記事）には、部屋割り画面で割当済みの予約をドラッグ＆ドロップして別の空室へ移す操作が書かれています（確認の画面は出ないとされています）。未部屋割り一覧から部屋へ入れるドラッグについては、公式にも記載がありません。今回反応がなかったのは、未割当の行を動かそうとしたためかもしれません。

部屋割り表の予約代表者の欄はフリガナで表示されます（例：タネガシマサトトキ）（2026/10/09確認）。

5. 自動部屋割りの仕組み

物件管理 → 物件情報 → 詳細を見る → 自動部屋割り設定
管理者のみ設定変更
  1. 自動部屋割りの時期を、チェックイン当日から90日前の範囲で選びます。
  2. 必要に応じてローテーション部屋割りと、部屋ごとの優先順位を設定します。
  3. 設定された時期になると、午前1時頃から日次バッチで割り当てられます。
  4. 割当時期を過ぎてから入った予約は、即時に割り当てられます。
  5. 割当後は「部屋割り表」または予約詳細で結果を確認します。
複数部屋がある施設の公式推奨「当日チェックインの予約のみ実行」が推奨されています。早く割り当てすぎると、連泊予約に部屋移動が発生したり、OTAからの部屋タイプ変更が反映されなくなったりするためです。

6. 自動部屋割りが行われない／失敗した

確認すること内容
部屋タイプ予約と各部屋に部屋タイプが設定されているか
実行時期設定した「チェックイン何日前」の時期に達しているか
空室対象部屋タイプに空きがあるか。前後予約の入退室時刻も確認
定員予約人数が部屋詳細の定員を超えていないか
ブロック故障・修理などのブロック期間と重なっていないか
「割り当てられる部屋がありません」右上の「自動割当」の確認画面でこう出た予約は、空いている同じタイプの部屋がない予約です。未割り当てのまま残るので、手で割り当てるか責任者へ相談します（2026/10/09確認）
清掃状態清掃待ちの部屋も割当候補になりました（例：早めにチェックアウトして清掃待ちの410が、翌日の予約に割り当てられた）。清掃が終わっているかは、割り当て後に必ず清掃予定表で確認してください（2026/10/09確認）
エラーを消すために別タイプへ入れない予約の部屋タイプ、料金、在庫が食い違う可能性があります。失敗通知と対象予約を記録し、責任者へ連絡します。

未割当予約の探し方

方法1：予約管理 → 予約情報 → 条件を選択して絞り込み → 部屋割当状況「未部屋割り」

「条件を選択して絞り込み」を押すと「条件を設定してください」パネルが開きます。部屋割当状況の選択肢は「未部屋割り／部屋割り済み／自動部屋割り失敗／部屋タイプから未割り当て」です。チェックインなどの期間を入れないと一覧が表示されません（期間は1年以内）。例：チェックイン 2026/10/01〜10/31 ＋ 未部屋割り → 14件。未割り当ての予約は、部屋名の欄に「（キャビン）」のように部屋タイプだけが括弧付きで表示されます（2026/10/09確認）。

方法2：予約管理 → 部屋割り表 → 基準日を指定 → 未部屋割り一覧

方法3：ダッシュボードの「予約状況」の表で、「未部屋割り」の数字を押すと部屋割りのページへ、「自動部屋割り失敗」の数字を押すと該当の予約へ移動します（ダッシュボードの見方）。公式マニュアルでは、自動部屋割りに失敗すると「自動部屋割りが失敗しました」と通知されるとされています。

7. フロア一括割当

責任者のみ

修学旅行などで、指定したフロアの全客室を新規予約時に確保する機能です。通常予約には使用しません。

  • フロアと各部屋の階数設定が必要
  • 予約詳細表示設定で「フロア一括割当」を有効にする必要がある
  • 新規予約の作成時だけ使用できる
  • 既存予約の変更には「宿泊変更」を使用する
オーバーブッキングでも保存できる仕様です公式記事では警告後にOKを押すと保存できるとされています。あらきホテルでは運用ルールが確定するまで、警告を進めず責任者へ連絡してください。

8. 割り当てを変更・解除する

部屋の入れ替えは「ルームチェンジ」も使えます宿泊期間全体の部屋を別の部屋に入れ替えるときは、ルームチェンジが使えます（客室の状況表の部屋の詳細、または予約詳細の部屋割り当ての入れ替えアイコンから。ルームチェンジ）。公式マニュアルでは、候補の部屋が1つ提案され、「他の候補を一覧で表示する」から選び直せるとされています。連泊の途中から部屋を移るときは、下の「宿泊変更」→「部屋変更」で移動日以降の部屋を変えます（部屋の途中変更）。
予約詳細 → 宿泊変更 → 部屋変更
  1. 変更理由と対象日を確認します。
  2. 移動先の空室・清掃・ブロック・定員を確認します。
  3. 対象日のセルから新しい部屋を選択します。
  4. 連泊の途中変更なら、移動日以前と以後の部屋番号を確認します。
  5. 保存後、鍵・清掃・次シフトへ旧部屋と新部屋を共有します。
「割当解除」「日程削除」は別の操作です割当解除は部屋番号を外す操作、日程削除はその部屋の利用日程を予約から外す操作です。目的が分からない場合は押しません。
割当解除すると部屋タイプも消えます「宿泊変更」→「部屋変更」で「割当解除」をして保存すると、部屋番号だけでなく部屋タイプも消えました（予約詳細の部屋タイプが「未入力」、宿泊変更の人数変更で「部屋タイプ未選択」）（2026/10/09確認）。部屋タイプが空のままだと、自動部屋割りの対象にならず、在庫の数も合わなくなるおそれがあります。割当解除の後は、「人数変更」で部屋タイプを選び直して保存してください。部屋タイプを入れ直せば、自動部屋割りの対象に戻ります（2026/10/10確認）。

9. HOTEL SMART・現場への確認待ち

下記が確定するまで、「部屋割り表」でのドラッグ操作と設定変更は責任者対応とします。

  • 部屋割り表で、未部屋割り一覧から部屋へドラッグして割り当てられるか（公式には、割当済みの予約を別の空室へ移すドラッグだけが書かれています）
  • 割当後にOTAの部屋タイプが変わったとき、予約詳細で手で直してよいか、自動更新との関係はどうなるか（公式は「一度部屋割りされると反映されない」とだけ書いており、修正手順はありません。取り込んだ部屋タイプがそもそも違うときは、サイトコントローラー連携設定の「部屋タイプ割り当て」を確認するよう案内しています）
  • 誤割当の操作履歴・変更者を確認できるか（公式で履歴を確認できるのは、料金・精算の操作履歴のCSVと、オペレーターメモに自動で残るチェックイン／アウト・キャンセル・自動更新の停止／再開だけで、部屋割りの履歴の記載はありません）
  • フロア一括割当を使えなくできるか（公式では、物件詳細の〖予約詳細表示設定〗で「フロア一括割当」をONにしたときだけ使える機能とされています。あらきホテルの今の設定（ON／OFF）を確認すれば足ります。権限ごとの制限の記載はありません）

確認済み

  • 部屋割り表の「自動割当」ボタンは、押したときに、基準日にかかる未割当予約を確認画面つきで割り当てます。定期処理は、毎日未明に当日チェックインの予約を割り当てます（2026/10/09確認）。
  • 清掃待ちの部屋も割当候補になる（2026/10/09確認）。
  • あらきホテルの今の設定：自動部屋割り「当日チェックインの予約のみ実行」、ローテーション部屋割り「行う」、部屋割り優先順位は全105室「未指定」（2026/10/09確認）。
  • 手動で割当解除した予約も、部屋タイプが入っていれば自動処理の対象になり、再割当されました（割当解除した当日チェックインの予約に、翌朝までに同じ部屋が再割当された。2026/10/10確認）。割当解除で部屋タイプまで消えた場合は対象にならないため、8. の注意のとおり部屋タイプを入れ直してください。
