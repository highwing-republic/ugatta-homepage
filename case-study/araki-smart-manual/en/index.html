4 rules to learn first

The basics for avoiding mistakes

① Check the dateBefore you operate, read the displayed stay date / target date out loud.
② Match the guestCheck not only the name but also one of: stay date, phone number or number of guests.
③ Save onceEven if the screen is slow, do not click repeatedly; check the result in the list.
④ If unsure, stopFor charges, refunds and external reservations, do not change anything on a guess; check with the manager (person in charge). The front desk can cancel reservations, but always report to the manager after you do.
